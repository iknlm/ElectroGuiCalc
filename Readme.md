# ElectroGuiCalc

**by iknlm** — калькулятор электрика для Windows: кабель, автомат, ток КЗ, заземление, двигатели, справочник и лекции.

Написан на C++ с Dear ImGui и DirectX 11. Интерфейс на русском и английском.

---

## Возможности

- **Кабель** — сечение, падение напряжения, проверка тока КЗ (Ik), максимальная длина линии
- **Автомат** — подбор номинала, характеристики B / C / D
- **Двигатель** — ток, пусковой ток, автомат, контактор, тепловое реле, схема звезда / треугольник
- **Нагрузка, заземление, формулы, даты, конвертер единиц, инженерный калькулятор**
- **Справочник** — цвета проводов, IP, категории перенапряжения, AWG, допустимые токи
- **Управление окнами Windows** — перемещение, размер, свернуть, поверх всех, завершить процесс
- **История расчётов** с экспортом в CSV
- **Лекции без интернета** — PDF из папки `lectures`
- **Темы и цвета (HSB)**, анимированный фон, переключение EN / RU

## Сборка

Нужны **Visual Studio 2019 / 2022** (рабочая нагрузка «Разработка классических приложений на C++») и **Windows SDK**.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/iknlm/ElectroGuiCalc.git
   ```

2. Откройте `ElectroGuiCalc.sln` в Visual Studio.

3. Выберите конфигурацию **Release** и платформу **x64**.

4. Нажмите **Сборка → Собрать решение** (Ctrl+Shift+B).

Готовый файл появится в `x64\Release\ElectroGuiCalc.exe`.

> Библиотека Dear ImGui уже лежит в папке `imgui`, отдельно ничего скачивать не нужно.

---

## Что должно лежать рядом с .exe

```
ElectroGuiCalc.exe
fonts\fa-solid-900.ttf     (иконки)
lectures\*.pdf             (лекции, необязательно)
```

Файл `settings.ini` программа создаёт сама при закрытии.
