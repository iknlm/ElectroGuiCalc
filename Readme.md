ElectroGuiCalc — автономный инженерный калькулятор для электромонтажников и проектировщиков. Настольное приложение для Windows на C++ с графикой на DirectX 11 и Dear ImGui. Вся логика, рендеринг и интеграция с WinAPI собраны в один файл.

 Интерфейс и графика
Custom Win32 Window: окно без системных рамок, скругления в стиле Windows 11, плавная анимация затухания, корректное перетаскивание и сворачивание.

Анимированный фон: интерактивная сетка точек с плывущими огоньками и подсветкой под курсором.

Кастомные виджеты: флажки с рисующейся галочкой, кнопки - / + с автоповтором, поля ввода с плашками единиц (кВт, В, м, А), плавные переключатели.

Темы: 8 готовых тем + редактор палитры через HSB с ограничением яркости фонов.

Локализация: RU | EN с мгновенным переключением. Autocomplete настроек в settings.ini.


 Калькуляторы
Математика: инженерный калькулятор (18 операций, факториалы до 170, тригонометрия, история, π и e).

Кабель: сечение по мощности/току с учетом материала (Cu/Al), фазности, прокладки (воздух, труба, земля, вода) и изоляции (ПВХ, СПЭ, резина). Включает ручное сечение, падение напряжения (В/%), ток КЗ по петле фаза-ноль, проверку автоматов B/C/D и таблицу максимальных длин при падении ≤ 5%.

Нагрузка: ток по мощности, напряжению и cosφ, потребление в кВт·ч за сутки.

Автомат: подбор номинала (6–125 А) с коэффициентом запаса (1.0–2.0) и подсказками по кривым B/C/D.

Заземление: сопротивление заземлителя по грунтам и количеству электродов.

Двигатель: прямой и обратный расчет мощности/тока, КПД, пусковые токи для 4 способов пуска. Схема обмоток (Звезда / Треугольник).

Формулы: шпаргалки по электрике, алгебре и геометрии.

Даты: календарный калькулятор с быстрыми кнопками (+1д, +7д, +30д).

2. Инструменты
Конвертер: 16 направлений перевода (AWG, л.с., температура, длины, массы, время).

Окна (WinAPI Manager): диспетчер окон Windows. Поиск процессов, превью, изменение размеров, позиционирование, фокус, «поверх всех окон», завершение. Встроена защита от закрытия самого калькулятора.

Справочник: таблицы кодировки цветов проводов (IEC, UK, DC/USA), классы IP, CAT I–IV, обозначения на схемах и токи медных жил.

История: журнал до 500 записей с экспортом в CSV (UTF-8 BOM) для Excel.

3. Разное
Настройки: управление конфигурацией.

Справка & Лекции: офлайн-обучение. Программа открывает 12 лекций по электротехнике (PDF, DOCX) из папки lectures.
